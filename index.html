Tentang Saya

Menghubungkan Alur Bisnis Enterprise dengan Analisis Data Modern

Sebagai mahasiswa Sistem Informasi, saya menggabungkan perspektif proses bisnis enterprise dan rekayasa data. Di satu sisi, saya memahami bagaimana proses bisnis perusahaan beroperasi secara nyata melalui konfigurasi modul SAP S/4HANA (P2P & O2C) serta integrasi antarmuka modern SAP Fiori dengan jurnal akuntansi keuangan (FI).

Di sisi lain, saya memiliki ketertarikan kuat dalam rekayasa data dan *business intelligence*, memanfaatkan SQL, Microsoft Power BI, Tableau, VS Code, dan machine learning untuk memproses data mentah menjadi wawasan bisnis prediktif yang mudah dipahami dan bernilai strategis.
